Objective

To visualize a straight line in space and obtain its front view and top view using orthographic projection.

Principle

A point is projected perpendicular to a reference plane. The front view is projected on the Vertical Plane (VP), while the top view is projected on the Horizontal Plane (HP). The XY line represents the intersection of HP and VP.

Front view length = √[(Δx)² + (Δz)²]
Top view length = √[(Δx)² + (Δy)²]
Δz = L sin α;   Δy = L sin β
Δx = L √[1 − sin²α − sin²β]

Geometry condition: sin²α + sin²β must not exceed 1 for a real line direction with the specified two inclinations.

Procedure

  1. Set the true length of the line using the length slider.
  2. Set the inclination with HP (α) and inclination with VP (β).
  3. Specify the first end's distance above HP and in front of VP.
  4. Observe the 3D line and rotate the model to understand its position in space.
  5. Read the front view and top view lengths and apparent angles.
  6. Use the animation to see the line and its projected views being constructed.

Result

The front and top projections are generated from the selected spatial coordinates. Record the displayed projection lengths and apparent angles in the observation table.

Teaching note: This module uses a direct 3D coordinate construction for learning. It is a visualization aid; students should still follow the prescribed engineering drawing conventions and manual construction sequence in their record work.
